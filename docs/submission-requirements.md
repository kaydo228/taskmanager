# Матрица требований к сдаче

Матрица сопоставляет требования `homework.pdf` с проверяемыми артефактами текущего репозитория.

- **закрыто** — есть прямое воспроизводимое доказательство;
- **частично** — часть требования доказана, но финальная проверка ещё не выполнена;
- **отсутствует** — требуемого исторического или текущего артефакта нет.

## Исторические пробелы

В репозитории нет сохранённого наивного прогона, аутентичного дизайн-скриншота «до» с теми же данными и заполненной первой сессии. Эти артефакты не реконструировались задним числом: такое восстановление создало бы выдуманное доказательство и противоречило бы правилам задания.
