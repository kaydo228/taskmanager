# Taskflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Построить Taskflow: Next.js-лендинг и React-кабинет с доступной локальной мини-доской задач.

**Architecture:** `pnpm` workspace и Turborepo содержат независимые `apps/landing` и `apps/dashboard`. Доска соблюдает FSD, а минимальные UI-примитивы экспортируются из `packages/shared/src/ui`; данные задач валидируются Zod и сохраняются через единый localStorage-репозиторий.

**Tech Stack:** TypeScript, pnpm, Turborepo, Next.js, Vite, React, React Router DOM, React Hook Form, Sileo, `@dnd-kit/*`, Zod, Vitest, React Testing Library, Playwright.

## Global Constraints

- Не добавлять CDN, API, сервер, авторизацию, аналитику или пакеты вне перечисленного стека без согласования.
- Не удалять `sessions/`, `materials/`, `homework.pdf`, скриншоты и демо-данные.
- Интерфейс и документы — на русском; код — на TypeScript с английскими идентификаторами.
- До финального ответа обязательны `pnpm build`, `pnpm test`, `pnpm lint`, `pnpm format:check`, браузерные проверки и скриншоты 360/1440 px.
- В текущей среде создание `.git` запрещено: фиксировать состояние в `sessions/`; коммиты и push выполнить после передачи работы в Git-окружение с правом записи.

## File Structure

- `package.json`, `pnpm-workspace.yaml`, `turbo.json` — общие команды workspace.
- `apps/landing` — Next.js-лендинг с CTA в кабинет.
- `apps/dashboard/src/app` — роутер, глобальные стили, провайдеры.
- `apps/dashboard/src/{pages,widgets,features,entities,shared}` — FSD-слои кабинета.

- `apps/dashboard/src/entities/task` — схема, типы, демо-данные и localStorage-репозиторий.
- `apps/dashboard/src/**/*.test.tsx` — модульные и компонентные тесты.
- `apps/dashboard/e2e/board.spec.ts` — проверка состояний, доступности и адаптива.

- [ ] **Step 3: Implement the smallest schema and repository**

```ts
export const taskSchema = z.object({
  id: z.string().uuid(),
  title: z.string().trim().min(1),
  description: z.string(),
  priority: z.enum(['low', 'medium', 'high']),
  dueDate: z.string().date(),
  status: z.enum(['todo', 'in-progress', 'done']),
  createdAt: z.string().datetime(),
});

export function loadTasks(storage: Storage): Task[] {
  const parsed = z
    .array(taskSchema)
    .safeParse(JSON.parse(storage.getItem(KEY) ?? '[]'));
  return parsed.success ? parsed.data : [];
}
```

Wrap `JSON.parse` in `try/catch`; generate nine deterministic demo records across all statuses.
