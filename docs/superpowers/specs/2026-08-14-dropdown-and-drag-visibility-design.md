# Дизайн dropdown и восстановления карточки после drag

## Цель

Исправить карточку, которая остаётся невидимой после первого переноса, и унифицировать dropdown статуса и приоритета в стиле Taskflow.

## Drag-and-drop

`TaskCard` не должен одновременно передавать `opacity` Motion и обычному inline-style. Значение видимости будет контролироваться одним путём: Motion получает `opacity: isDragging ? 0 : 1`. После завершения или отмены drag `isDragging` становится `false`, поэтому карточка явно анимируется обратно к `opacity: 1` без ожидания следующего переноса.

Порядок задач, обработчик drop и формат localStorage не меняются.

## Общий dropdown

В `packages/shared/src/ui` появится управляемый компонент `Dropdown` с контрактом `label`, `options`, `value` и `onChange`. Он используется:

- в карточке — для статуса;
- в форме создания и редактирования — для приоритета через `Controller` React Hook Form.

Кнопка показывает выбранное значение и CSS-chevron. Chevron поворачивается при открытии, не использует emoji или внешний icon-пакет. Меню использует существующие цвета, рамки, радиусы и тени Taskflow.

## Доступность

- Кнопка имеет `aria-haspopup="listbox"` и `aria-expanded`.
- Опции доступны через Tab и активируются Enter/Space.
- Esc закрывает меню и возвращает фокус кнопке.
- Клик вне компонента закрывает меню.
- Выбранная опция помечается через `aria-selected`.

## Проверка

- Компонентный тест: dropdown открывается, выбирает значение и закрывается по Esc.
- Тест формы: выбранный приоритет попадает в `onSubmit`.
- Регрессия карточки: Motion не получает конкурирующий `style.opacity`; после окончания drag целевое состояние равно `opacity: 1`.
- `pnpm build`, `pnpm test`, `pnpm lint` и форматирование изменённых файлов.
