# Taskflow Board Polish Design

## Цель

Сделать доску понятнее при работе мышью: добавить drag overlay, быстрые действия, добавление в колонку и кастомные меню; завершить Motion-анимации лендинга.

## Интерфейс

- Каждый раздел лендинга анимированно появляется через Motion с коротким stagger.
- Карточка показывает дату слева в строке метаданных. Во время перетаскивания отображается полупрозрачная копия карточки с названием и приоритетом.
- Заголовок каждой колонки содержит кнопку `+ Добавить`, открывающую форму новой задачи с уже выбранным статусом колонки.
- Кнопка `⋯` открывает кастомное меню действий: «Редактировать» и «Удалить». Удаление происходит сразу и подтверждается Sileo toast.
- Смена статуса использует стилизованное раскрывающееся меню вместо нативного select. Основной сценарий — мышь; Tab и Esc сохраняются для требований задания.
- CTA создания задачи получает явный белый цвет текста как в JSX, так и в CSS.

## Motion и доступность

Motion длится 160–320 мс. `prefers-reduced-motion` отключает движение. Dropdown закрывается по Esc, кнопки доступны из Tab; анимации не перемещают фокус.

## Проверка

- Тесты: добавление задачи в выбранную колонку, удаление, открытие меню действий.
- Ручной прогон: drag overlay, меню мышью, Esc, reduced motion, 360/1440 px.
- `pnpm build`, `pnpm test`, `pnpm lint`, `pnpm format:check` проходят.
