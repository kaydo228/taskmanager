## Размышления

Папка `native_run` предоставлена пользователем как аутентичный результат наивного прогона. Нужно проверить, что она запускается и что её содержимого достаточно для честного сравнения с итоговым проектом. Отдельный план не создаётся по прямой просьбе пользователя; минимальный объём работы — сохранить исходник без переписывания, добавить проверяемое сравнение и исправить документацию только по подтверждённым фактам.

Первый полный gate опроверг готовность: `format:check` нашёл четыре неформатированных исходника внутри `native_run`. Переписывать их Prettier означало бы менять сохранённый результат наивного прогона, поэтому выбран узкий `.prettierignore` только для этой архивной папки. Build, 33 теста, lint и три теста самого прогона при этой попытке прошли.
