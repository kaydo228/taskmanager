## Готово

- Доска поддерживает перенос задачи в пустую колонку, конец колонки и до/после другой карточки; порядок хранится в существующем массиве localStorage.
- Карточки используют `SortableContext`, overlay очищается при отмене drag, а mouse/touch/keyboard сенсоры настроены для предсказуемого перетаскивания.
- Приоритет в модалке и статус карточки используют единый кастомный dropdown с CSS-chevron, мышью, Enter/Space/Esc и закрытием вне меню.
- Карточка после первого drag сразу получает видимость обратно: `TaskBoard.activeTask` единолично управляет скрытием исходной карточки, а dnd-kit — transform/transition. Motion удалён с draggable-узла, поэтому устаревший внутренний `isDragging` не может оставить новую карточку прозрачной.
- CTA «Создать задачу» имеет явный inline светлый цвет, поэтому не зависит от каскада стилей; дата не пересекается с drag-handle.
- Dialog анимированно появляется и завершает exit-переход перед закрытием, кроме режима reduced motion.
- Перенос и вставка между карточками проверены unit-тестами; реальный pointer-drag между колонками подтверждает `opacity: 1` через 600 мс после первого переноса без второй задачи.
- Браузерная проверка на 360 и 1440 px выполнена без ошибок консоли; снимки сессий 6 и 7 лежат в `screenshots/`.
- `pnpm build`, `pnpm test` (15 dashboard + 3 landing теста), `pnpm lint` и `pnpm format:check` проходят.
- Четыре секции лендинга используют единый редакционный Motion-каскад: hero при загрузке, колонки preview, шаги 01–03 и финальный CTA при первом входе во viewport.
- Viewport-анимации настроены с `once: true` и `amount: 0.2`; после обратной прокрутки секции не скрываются и не запускаются повторно.
- При `prefers-reduced-motion` секции сразу получают видимое состояние без opacity/transform-перехода; поведение защищено компонентным тестом.
- Лендинг проверен в браузере на 1440×900 и 360×800 без ошибок консоли; снимки лежат в `sessions/session-8-landing-1440.png` и `sessions/session-8-landing-360.png`.
- Generated `apps/landing/next-env.d.ts` исключён из Prettier через `.prettierignore`, поэтому `next build` больше не делает последующий `format:check` красным.
- Поле описания задачи заменено WYSIWYG-редактором Tiptap с абзацами, H2/H3, акцентами, списками, цитатами, кодом, HTTP(S)-ссылками и undo/redo; toolbar доступен с клавиатуры и адаптивно переносится на 360 px.
- Форматированный документ хранится внутри прежнего `Task.description: string` с префиксом `tiptap:`; localStorage, ключ, Zod-схема и форма массива задач не изменены. Старые текстовые и повреждённые описания безопасно отображаются как текст.
- Карточки используют статический React-рендерер Tiptap без `dangerouslySetInnerHTML`; опасные протоколы ссылок отбрасываются валидатором.
- Расчёт вставки drag-and-drop сравнивает центр drag overlay с центром целевой карточки, поэтому карточки разной высоты надёжно вставляются между соседями.
- Редактор проверен созданием, reload, редактированием, Tab/Space/Enter/Esc и отсутствием горизонтального overflow; снимки лежат в `sessions/session-9-editor-360.png` и `sessions/session-9-editor-1440.png`.
- `pnpm build`, `pnpm test` (30 dashboard + 3 landing теста), `pnpm lint`, `pnpm format:check` и 3 Playwright e2e проходят.
- Логотип dashboard открывает лендинг через `VITE_LANDING_URL` с локальным fallback `http://localhost:3001`; адрес совпадает с dev-портом Next.js и проверен реальным браузерным переходом без ошибок консоли.
